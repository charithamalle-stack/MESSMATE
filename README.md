# 🍽️ MESSMATE — Smart Hostel Mess Management System

**Making hostel mess management more transparent, organized, and student-friendly.**

MESSMATE is a web-based hostel mess management platform that connects students and mess committees through weekly meal schedules, structured food feedback, and performance analytics.

It helps students share their dining experiences and enables mess committees to understand feedback and identify areas for improvement.

## ✨ Features

### 1. 📅 Weekly Menu
- View the weekly hostel mess menu.
- Check meals across breakfast, lunch, snacks, and dinner.
- Rate meals and share dining experiences.

### 2. 📝 Student Feedback
- Submit feedback for individual meals and dishes.
- Rate food using a star-rating system.
- Provide feedback across multiple categories:
  - Taste
  - Food Quality
  - Quantity
  - Hygiene
  - Variety
- Add optional comments.
- Submit feedback anonymously.

### 3. 📊 Committee Dashboard
- View total ratings and feedback received.
- Monitor overall food ratings.
- Identify top-rated and low-rated meals.
- View meal-wise performance and student opinions.

### 4. 📈 Feedback Analytics
- Analyze feedback category-wise.
- Identify recurring complaints and improvement areas.
- View dish-wise feedback.
- Understand student satisfaction through organized data.

### 5. 💡 Structured Feedback System
Instead of collecting only general comments, MESSMATE organizes student feedback into specific categories, helping committees identify what needs improvement.

## 🚀 Getting Started

Follow these steps to run MESSMATE locally.

### Prerequisites
- Node.js
- npm
- Git

### 1. Clone the repository

```bash
git clone https://github.com/charithamalle-stack/MESSMATE.git
```

### 2. Navigate to the project

```bash
cd MESSMATE/client
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

### 5. Open in your browser

Visit:

```text
http://localhost:5173/
```
## ⚙️ Current Implementation & Limitations

- The application currently uses browser LocalStorage for data storage.
- Data is stored locally in the browser and is not automatically synchronized between different users or devices.
- A shared backend and database would be needed for real-time multi-user data synchronization.
